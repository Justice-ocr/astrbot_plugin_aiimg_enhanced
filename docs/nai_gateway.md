# NovelAI 第三方 GET 网关

## OpenAI Chat 协议中转

商家提供 `/v1/chat/completions` 时，使用「OpenAI Chat图」模板，
不要选择 GET 或原生协议模板。按现有 Chat 配置填写地址、Key 和商家模型 ID。
开启「自然语言转 NAI 标签」后，文生图和改图均会先将描述转成英文标签，
再由原有 Chat 后端构造请求；不会注入 NAI 原生的采样或参考图参数。
开关默认关闭，旧配置行为不变。转换 LLM ID 留空跟随当前会话，
也可指定独立的 AstrBot 文本模型服务商，建议不要选只输出图片的模型。
改图仅在商家支持图片输入时启用；转换 LLM 当前只处理文字，不识图。

## GET 协议中转

在 Web 设置中新建「NovelAI 第三方 GET 网关」服务商。
该模板参考 nai_brush 的请求协议独立实现，并非所有名为 NAI 的接口都适用。

| 配置 | 示例 |
| --- | --- |
| 服务商 ID | nai |
| Base URL | https://your-gateway.example |
| 生成接口路径 | /generate |
| 模型名称 | nai-diffusion-4-5-full（以商家模型名为准） |
| 默认输出尺寸 | 832x1216 |
| 鉴权方式 | URL token 参数，或商家要求的 Bearer 请求头 |

请求方式为 GET，发送 `tag`、`model`、`size`，以及配置的
`artist`、`negative`、`sampler`、`steps`、`scale`、`cfg`、
`noise_schedule`、`seed`。额外请求体输入框在本模板中代表额外查询参数，
使用 JSON 对象，例如 `{"nocache": true}`。

URL token 鉴权与参考插件一致，但 Token 可能出现在网关或代理的访问日志中。
请使用可信的 HTTPS 网关；商家支持 Bearer 时优先选择请求头鉴权。
模板不跟随重定向，不自动重试生成请求，避免泄漏凭据或重复扣费。

支持图片二进制、JSON 图片 URL 和 Base64 响应。
只支持文生图，不支持参考图、改图、角色保持或 Vibe Transfer。
默认原样传递提示词。开启「自然语言转 NAI 标签」后，生成前通过 LLM
将描述转换为英文标签，再由后端添加配置的前缀、画师和负面词。
「转换 LLM ID」填写 AstrBot 文本模型服务商 ID，留空使用当前会话的模型。
转换只针对本模板，适用于命令、LLM 工具和任务文生图入口。
转换失败、返回空标签或超过 60 秒时不会提交该 NAI 生图请求。
关闭开关即可直接提交手写标签。

若商家提供 `/v1/images/generations`，应选择现有 OpenAI Images 模板。
若商家提供原生 `/ai/generate-image` JSON/ZIP 协议，本模板不适用。

## 原生协议中转模板

商家兼容 NAI 原生协议时，选择新增的「NovelAI 原生协议中转」。
Base URL 为 `/ai/generate-image` 之前的地址，使用 Bearer 鉴权。
文生图复用现有绘图入口，参考图复用改图、自拍和继续改图入口。
自然语言转标签同样可用于文生图和改图。

- 底图重绘：必须一张底图，强度为重绘幅度。
- 角色保持：必须一张身份参考图，自动处理为指定尺寸 JPEG。
  当前会话人设的参考图沿现有自拍入口传入；若传入多张则明确报错，
  暂不自动按身份、服装、姿势等职责筛选。
- 风格 / 氛围参考：最多 9 张图片，使用统一的参考强度与信息提取度。
  需要商家提供 `/ai/encode-vibe`。编码按地址、凭据、模型、提取参数和图片隔离，
  内存最多缓存 32 条，重启清空。仅避免重复编码，不免除生图费用。

可配置多个服务商 ID 分别用于重绘、角色保持、Vibe，并在对应功能链选择。
每次请求只使用一种参考模式，不混用角色保持与 Vibe。
当前尚未提供逐图权重、视觉参数提取、多角色坐标布局和历史参数快照；
继续改图会使用当前服务商配置，而非恢复上次配置。
实际能力取决于商家，不兼容的接口会明确报错，不回退成普通文生图。
